💡 自動寄信啟用說明（免費免伺服器 FormSubmit 服務）：

  1. 輸入您的信箱後，點擊右上角 「📨 儲存並發送測試通知信」。
  2. 請前往您的信箱（若無請檢查垃圾郵件匣），找到主旨為 「FormSubmit - Confirm your email address」 的信件，點擊信中的 「Activate Form」 按鈕。
  3. 啟用完成後，未來只要買家在前台送出訂單，系統就會在背景自動寄送新訂單通知信到這個信箱！

Step 1. 免費永久架站

🚀 使用 GitHub Pages 設立穩固的專屬網站

  1. 登入 GitHub.com，進入您的專案倉庫（例如 Momhandmade）。
  2. 點擊上方 「📥 下載最新網站檔案 (index.html)」 按鈕，系統會將您目前設定好的商品、價格、通知信箱與匯款資料打包成乾淨的 index.html。
  3. 在 GitHub 專案頁面點擊 「Add file」➔「Upload files」，將下載的 index.html 上傳並點擊綠色的 「Commit changes」。
  4. 等待約 1 分鐘，即可在您的 GitHub Pages 網址看到最新內容！
Step 2. 跨裝置訂單＆留言雲端同步（建議開啟）

☁️ 串接 GitHub Gist 雲端資料庫（讓買家下單、留言與賣家後台跨手機/電腦即時互通）

填入您的 GitHub Token 與 Gist ID 後，記得點擊上方「📥 下載最新網站檔案 (index.html)」重新上傳至 GitHub，這樣不同手機的買家下單時都會自動同步到同一個雲端資料庫！
