Step 1. 免費永久架站

🚀 使用 GitHub Pages 設立穩固的專屬網站

  1. 登入 GitHub.com，點擊右上角 「+」➔「New repository」 建立新專案（例如命名為 momhandmade，並勾選 Public）。
  2. 點擊上方 「📥 下載最新網站檔案 (index.html)」 按鈕，系統會將您目前設定好的商品價格、圖片與匯款資料打包成 index.html。
  3. 在 GitHub 專案頁面點擊 「Add file」➔「Upload files」，將下載的 index.html 上傳並點擊綠色的 「Commit changes」。
  4. 進入專案頂部的 「Settings」➔ 左側選單「Pages」，在 Build and deployment 的 Branch 選擇 main 並按 Save。
  5. 等待約 1 分鐘，即可獲得永久免費、買賣家皆可隨時連線使用的穩固網址：https://您的GitHub帳號.github.io/momhandmade/！
